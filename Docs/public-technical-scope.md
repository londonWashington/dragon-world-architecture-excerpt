# Public Technical Scope

This repository is intentionally designed for public evaluation.

## Included

- High-level system responsibilities.
- Relationships between major technical layers.
- Implemented player-facing capabilities.
- Architectural principles and production intent.
- Selected system names where they improve clarity.

## Not included

- Production source code or assets.
- Complete method bodies or proprietary algorithms.
- Exact tuning values, thresholds, formulas, or hidden state machines.
- Internal file trees and implementation maps.
- Credentials, endpoints, account identifiers, or backend topology.
- Internal issue lists, build warnings, or debugging procedures.
- Unannounced roadmap, narrative reveals, or deferred encounter designs.

## Review access

Additional technical depth can be demonstrated privately through a guided code review, screen share, controlled repository access, or a purpose-built code sample. This provides stronger evidence than publishing the entire production implementation and allows the discussion to focus on the reviewer’s technical interests.

## Licensing status

This is a public portfolio and evaluation repository, not an open-source software distribution. No open-source license is granted.
